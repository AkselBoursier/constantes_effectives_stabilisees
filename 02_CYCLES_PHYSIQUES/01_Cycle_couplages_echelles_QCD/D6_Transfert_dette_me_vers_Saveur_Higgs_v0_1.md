# D6 — Transfert de la dette autonome `m_e` vers le cycle Saveur–Higgs v0.1

## 0. Statut

```text
statut : décision scientifique validée humainement le 26 juillet 2026 ;
issue : #49 ;
fonction : fixer le rang atteint par m_e dans le cycle 1,
           requalifier sa dette restante et déterminer son cycle d’accueil ;
autorité : décision validée, application aux couches actives encore distincte ;
ne vaut pas : instruction scientifique du Yukawa électronique,
               modification immédiate de la synthèse active,
               clôture documentaire automatique du cycle 1,
               ni ouverture du prochain lot Saveur–Higgs.
```

## 1. Question

> Après l’instruction de `m_p/m_e`, faut-il ouvrir immédiatement un dossier autonome `m_e` dans le cycle 1 ou transférer la dette restante vers le cycle Saveur–Higgs ?

Le critère est le gain scientifique marginal : une nouvelle instruction doit modifier le verdict, le rang probatoire, la cible attribuée ou la décision scientifique suivante, sans reproduire ce qui est déjà acquis.

## 2. Rang atteint dans le cycle 1

Le premier lot `m_p/m_e` a déjà établi au rang nécessaire :

```text
- quelle masse électronique entre dans le rapport ;
- le caractère composite et ajusté de sa détermination métrologique ;
- la différence entre masse physique, rapport sans dimension
  et paramètre théorique ;
- la relation structurelle m_e = y_e v / sqrt(2)
  dans le Modèle standard ;
- le fait que la précision de m_e ne mesure pas directement y_e ;
- l’impossibilité d’attribuer séparément une variation du rapport
  à m_p ou à m_e sans modèle supplémentaire.
```

Une instruction autonome immédiate de `m_e` dans le cycle 1 répéterait donc largement les distinctions déjà acquises. Son développement propre conduirait vers les masses renormalisées, le Yukawa électronique, l’échelle de brisure, les corrections radiatives et l’accès direct au Higgs : ce déplacement excède le gain propre du premier périmètre « couplages, échelles et QCD ».

## 3. Cycle d’accueil pertinent

Le cycle Saveur–Higgs articule précisément :

```text
échelle de brisure
→ couplages de Yukawa
→ matrices de masse
→ masses physiques
→ accès expérimentaux.
```

La dette restante de `m_e` y devient un cas-test discriminant de la différence entre :

```text
masse physique très précisément déterminée ;
paramètre de Yukawa inféré dans un cadre théorique ;
couplage direct au Higgs expérimentalement contraint ;
origine de la hiérarchie fermionique non expliquée.
```

Le transfert n’est donc ni un archivage ni une absorption. Il requalifie la question afin qu’elle soit instruite dans le réseau où elle produit un gain propre.

## 4. Décision

```text
D6-A — refuser l’ouverture immédiate d’un dossier autonome m_e
       dans le cycle 1, faute de gain marginal suffisant ;

D6-B — déclarer m_e instruite dans le cycle 1 au rang nécessaire
       pour interpréter m_p/m_e ;

D6-C — transférer la dette scientifique restante vers
       le cycle Saveur–Higgs ;

D6-D — reformuler cette dette comme problème
       masse physique / Yukawa électronique / échelle de brisure /
       accès direct au Higgs ;

D6-E — préparer la clôture ou suspension du premier périmètre
       du cycle 1, sans la confondre avec la clôture générale
       et définitive du cycle.
```

## 5. Périmètre futur recommandé dans Saveur–Higgs

La reprise devra rester compacte :

```text
S1 — relation structurelle :
     m_e, y_e, v, schémas et corrections nécessaires ;

S2 — accès :
     détermination métrologique de m_e
     versus contraintes directes et indirectes sur y_e ;

S3 — verdict :
     ce que la précision de la masse autorise,
     ce qu’elle n’autorise pas,
     et ce qui reste expérimentalement ouvert.
```

Cette structure n’est pas encore un lot ouvert. Elle fixe seulement la forme minimale de la dette transférée.

## 6. Conditions de réouverture dans le cycle 1

`m_e` ne doit revenir comme dette propre du cycle 1 qu’en présence d’un matériau modifiant son verdict local, par exemple :

```text
- nouvelle chaîne métrologique indépendante ;
- accès à une transformation de m_e non réductible à m_p/m_e ;
- nouvel ajustement CODATA modifiant son statut ;
- mesure directe du Yukawa électronique ;
- résultat reliant explicitement m_e aux dettes propres
  de couplage et d’échelle du cycle 1.
```

Une simple amélioration de précision ou une nouvelle reformulation théorique ne suffit pas si elle ne modifie ni l’attribution, ni le rang, ni la décision scientifique.

## 7. Effet sur le premier périmètre du cycle 1

Après application documentaire distincte, le premier périmètre pourra être décrit ainsi :

```text
QCD–T1 : clos pour le premier lot ;
alpha : clos pour le premier lot ;
m_p/m_e : clos pour le premier lot ;
m_e : dette propre transférée vers Saveur–Higgs ;
test global alpha_s : suspendu faute de matériaux ;
cycle 1 : premier périmètre clos ou suspendu,
          réouverture conditionnée à des matériaux discriminants.
```

Le choix entre les termes `clos` et `suspendu` doit être fixé lors de l’application aux couches actives. La décision scientifique déjà acquise est que le cycle 1 ne doit pas rester artificiellement ouvert par la seule présence historique de la dette `m_e`.

## 8. Hors périmètre

- aucune conclusion générale sur l’origine de la masse électronique ;
- aucune mesure directe de `y_e` inférée depuis la précision de `m_e` ;
- aucune réécriture rétroactive des sources DOCX ;
- aucune modification du cadre canonique ;
- aucune ouverture automatique d’un lot Saveur–Higgs ;
- aucune nouvelle taxonomie.

## 9. Décision d’application encore distincte

La présente décision autorise le transfert scientifique. Une opération documentaire séparée devra déterminer :

```text
- la formulation exacte de clôture ou suspension du premier périmètre ;
- la mise à jour de la synthèse active du cycle 1 ;
- l’inscription de la dette dans le cycle Saveur–Higgs ;
- la synchronisation minimale de l’index et des points d’entrée.
```
