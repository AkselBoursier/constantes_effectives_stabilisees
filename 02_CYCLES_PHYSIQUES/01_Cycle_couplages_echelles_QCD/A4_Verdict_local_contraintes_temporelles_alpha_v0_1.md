# α4 — Verdict local sur les contraintes temporelles de `alpha` v0.1

## 0. Statut

```text
statut : verdict local adopté sous délégation procédurale ;
date : 26 juillet 2026 ;
opération : α4, issue #39 ;
entrée directe : A4_Fiche_contraintes_temporelles_alpha_v0_1.md ;
fonction : statuer sur deux familles temporelles du premier lot ;
autorité : locale au dossier alpha, révisable à la synthèse finale ;
ne vaut pas : invariance temporelle universelle,
               contrainte sur toutes les fréquences,
               ou verdict spatial, cosmologique ou sur alpha(Q²).
```

## 1. Réponse courte

Les comparaisons d’horloges `171Yb+` n’observent pas de signal significatif compatible avec une dérive linéaire lente de `alpha` ni avec un couplage à la modulation annuelle du potentiel gravitationnel solaire. Ces non-détections sont discriminantes pour les familles, périodes, sensibilités et incertitudes déclarées.

Elles ne démontrent pas que `alpha` est absolument invariante dans le temps.

## 2. Admission

```text
admission :
  mesure précise et répétée du rapport E3/E2 ;
  forte sensibilité différentielle calculée à alpha ;
  série temporelle de plusieurs années ;
  contrainte sur une dérive linéaire :
    (1/alpha) d alpha/dt = 1.0(1.1) × 10^-18 yr^-1 ;
  contrainte sur un couplage annuel au potentiel :
    (c²/alpha) d alpha/dPhi = 14(11) × 10^-9 ;
  résultats compatibles avec zéro ;
  disponibilité publique des principales séries numériques ;
  rang de non-détection discriminante pour les deux familles.
```

## 3. Refus

```text
refus :
  traiter le rapport de fréquences comme mesure directe de alpha ;
  conclure à une invariance temporelle universelle ;
  identifier dérive linéaire et modulation annuelle ;
  étendre la contrainte à des oscillations ou transitoires non testés ;
  ignorer les coefficients de sensibilité atomique ;
  isoler alpha dans les comparaisons E3/Cs sans les autres paramètres ;
  confondre stabilité métrologique des horloges
  et preuve indépendante sur une constante fondamentale.
```

## 4. Suspension

```text
suspension :
  variations non linéaires arbitraires ;
  oscillations hors de la bande temporelle du premier lot ;
  événements transitoires ;
  dépendance aux modèles atomiques au-delà des coefficients employés ;
  reproduction numérique complète des ajustements ;
  combinaison exhaustive avec les horloges postérieures ;
  portée hors du laboratoire terrestre et de l’époque observée.
```

## 5. Contrôle P27

```text
famille : déclarée ;
sensibilité : établie par transitions différentielles ;
domaine : séries pluriannuelles ;
tolérance : incertitudes explicites ;
paramètres : pente ou amplitude annuelle ;
résultat : compatible avec zéro.
```

La non-détection soutient donc une contrainte sur la variation. Elle ne soutient ni une fixité exacte ni une exclusion de toute famille possible.

## 6. Rang du résultat

```text
rang :
  contrainte expérimentale locale sur des paramètres de variation ;

porteur du test :
  rapport de fréquences et sensibilité différentielle ;

transformation :
  temps linéaire ou potentiel solaire annuel ;

mode de soutien probatoire :
  non-détection discriminante ;

forme de maintien :
  absence de dérive ou modulation détectable
  dans les limites déclarées ;

limite :
  le maintien n’est attribuable qu’à la famille indexée.
```

## 7. Réponse à Q1 et Q2

### Q1

La frontière entre variation et maintien est indexée à un modèle temporel. Une pente ou une modulation compatible avec zéro produit une contrainte seulement parce que le dispositif aurait été sensible à cette forme de variation.

### Q2

Le maintien devient opératoire par l’assemblage des sensibilités atomiques, des rapports de fréquences, de la durée d’observation, des modèles ajustés et des budgets de reproductibilité. La question scientifique devient : « quelle variation aurait été détectable ? »

