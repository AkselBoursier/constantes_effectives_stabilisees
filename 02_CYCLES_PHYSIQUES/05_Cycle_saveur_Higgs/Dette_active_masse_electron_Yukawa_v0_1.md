# Dette active — masse électronique, Yukawa électronique et accès au Higgs v0.1

## 0. Statut

```text
statut : dette scientifique active transférée au 27 juillet 2026 ;
origine : décision D6 du cycle 1 ;
cycle d’accueil : Saveur–Higgs ;
fonction : fixer la question, le périmètre minimal et les conditions d’ouverture ;
ne vaut pas :
  lot scientifique déjà ouvert ;
  verdict sur l’origine de la masse électronique ;
  mesure directe du Yukawa électronique ;
  réécriture de la synthèse Saveur–Higgs v0.1 ;
  nouvelle taxonomie.
```

## 1. Origine du transfert

Dans le cycle 1, `m_e` a été instruite au rang nécessaire pour interpréter `m_p/m_e` : masse physique engagée dans le rapport, chaîne métrologique composite, relation structurelle au secteur électrofaible et impossibilité d’attribuer séparément une variation du rapport sans modèle.

Une instruction autonome supplémentaire dans ce cycle aurait principalement déplacé l’enquête vers le réseau Saveur–Higgs. La dette restante y est donc transférée plutôt que dupliquée.

## 2. Question active

> Que peut-on effectivement conclure sur le rapport entre masse physique de l’électron, paramètre de Yukawa, échelle de brisure électrofaible et accès expérimental direct au couplage Higgs–électron ?

La question distingue :

```text
m_e : masse physique très précisément déterminée ;
y_e : paramètre de Yukawa défini dans un cadre et un schéma ;
v : échelle du régime électrofaible brisé ;
H–e–e : interaction directement testable par des processus impliquant le Higgs.
```

La relation structurelle

```text
m_e = y_e v / sqrt(2)
```

ne rend pas ces quatre niveaux expérimentalement équivalents.

## 3. Gain propre attendu dans Saveur–Higgs

Le cas `m_e` doit éprouver la chaîne :

```text
échelle de brisure
→ couplage de Yukawa
→ paramètre de masse
→ masse physique
→ accès métrologique ou collisionnel.
```

Le gain recherché est de séparer :

- relation du Modèle standard ;
- inférence conditionnelle depuis `m_e` et `v` ;
- définition et renormalisation de `y_e` ;
- contrainte directe ou indirecte sur l’interaction Higgs–électron ;
- explication de l’origine ou de la hiérarchie, qui reste une question distincte.

## 4. Périmètre minimal recommandé

```text
S1 — relation structurelle :
     m_e, y_e, v, schémas et corrections nécessaires ;

S2 — accès :
     détermination métrologique de m_e ;
     contraintes indirectes sur y_e ;
     recherches directes du couplage Higgs–électron ;

S3 — verdict :
     ce que la précision de m_e autorise ;
     ce qu’elle n’autorise pas ;
     ce qui reste expérimentalement ouvert.
```

Cette structure est une borne. Elle ne crée pas automatiquement une fiche par expérience ni une reprise exhaustive du secteur de Higgs.

## 5. Matériaux nécessaires avant ouverture

L’ouverture de S1–S3 exige au minimum :

```text
- sources primaires sur la détermination actuelle de m_e ;
- définition de y_e et conventions de renormalisation pertinentes ;
- détermination de v dans le cadre standard ;
- recherches expérimentales directes et indirectes du couplage électronique ;
- séparation explicite entre masse mesurée, paramètre inféré
  et interaction directement contrainte.
```

## 6. Interdits

- ne pas déduire une mesure directe de `y_e` depuis la précision de `m_e` ;
- ne pas présenter `m_e = y_e v / sqrt(2)` sans préciser le cadre et les corrections ;
- ne pas confondre masse physique et paramètre renormalisé ;
- ne pas attribuer à la seule brisure électrofaible l’origine des hiérarchies de Yukawa ;
- ne pas réimporter l’ancienne classe « constante effective stabilisée » ;
- ne pas rouvrir le cycle 1 pour reproduire ce dossier.

## 7. Condition de sortie

La dette quitte ce statut lorsque :

```text
- un lot S1–S3 est explicitement ouvert et instruit ;
- ou une nouvelle décision établit que le gain marginal est insuffisant ;
- ou des matériaux déplacent la question vers un autre cycle mieux adapté.
```

Jusqu’à cette décision, la dette est active dans Saveur–Higgs mais le lot scientifique reste non ouvert.
