# Règles locales — cycles physiques

Ce fichier complète le `AGENTS.md` racine pour tout travail dans `02_CYCLES_PHYSIQUES/`.

Les dix cycles sont des terrains scientifiques distincts. Les règles transverses doivent être appliquées avec leur régime ; aucune consigne méthodologique n'est supposée produire la même opération dans tous les cycles.

## 1. Route de reprise

Avant une intervention scientifique :

1. lire le `AGENTS.md` racine ;
2. lire le présent fichier ;
3. lire le `README.md` des cycles ;
4. entrer dans le point d'entrée du cycle concerné ;
5. lire l'issue ou la décision active explicitement routée par ce point d'entrée lorsqu'elle existe.

Ne pas reconstruire l'état actif depuis les seuls numéros d'issues, dates, archives ou anciennes synthèses.

## 2. Représenter la science vivante, pas seulement les résultats

Un état scientifique de cycle ne se réduit pas à ses résultats qualifiés.

Lorsqu'une reprise, un audit ou une synthèse prétend représenter l'état réel du travail, rechercher séparément :

- question scientifique actuelle ;
- recherche ou investigation en cours ;
- résultats acquis et leur portée ;
- résultats négatifs et voies éliminées ;
- blocages matériels, computationnels ou méthodologiques ;
- décisions encore ouvertes ;
- condition concrète de reprise ;
- effet attendu sur le programme si la question est résolue.

Ne pas transformer une recherche en cours en résultat. Ne pas transformer une dette en priorité par défaut.

Cette discipline est particulièrement importante lors de toute réutilisation de la phase documentaire de l'audit #132 : la phase de résultats porteurs ne représentait pas à elle seule tout l'état scientifique vivant.

## 3. Les cycles restent premiers dans leur vocabulaire et leurs discriminants

Pour chaque cycle :

- employer d'abord le vocabulaire disciplinaire ;
- identifier la cible physique ou inférentielle réelle ;
- préciser transformation, régime, échelle/schéma/modèle, tolérance et condition de rupture lorsqu'une constance ou stabilisation est discutée ;
- distinguer propriété physique, qualité de l'accès, mode de constitution, procédure de mesure et représentation ;
- borner le verdict au discriminant réellement instruit.

Une catégorie transversale du projet ne remplace jamais les distinctions du domaine lorsqu'elles portent davantage d'information.

## 4. Passages entre cycles et entre domaines

Un résultat, une règle ou une question ne se transfère pas automatiquement d'un cycle à un autre.

Lorsqu'un rapprochement est proposé :

```text
question qui justifie le passage
→ objets effectivement comparables
→ ce qui est transféré
→ ce qui ne l'est pas
→ réinstruction dans le domaine compétent
→ verdict local seulement après cette réinstruction
```

Une question apparue en philosophie peut rouvrir une question scientifique réelle — formation d'un régime, conditions d'accès, constitution d'un objet ou d'une relation — mais elle ne modifie pas automatiquement le dossier physique. Comparer avec l'état scientifique antérieur peut alors être nécessaire pendant la réinstruction ; l'ancien état n'est pas effacé au nom d'une présentation du seul présent.

## 5. Science, computation et preuve

Toujours conserver :

```text
calcul
!= résultat machine
!= qualification technique
!= soutien probatoire
!= résultat scientifique
!= verdict scientifique
!= interprétation scientifique
```

Un changement de sampler, de harnais, d'oracle, de représentation ou d'infrastructure n'est pas une modification scientifique par lui-même. S'il peut changer la cible, les données, le prior, la paramétrisation scientifique ou l'interprétation, il devient une question scientifique distincte.

Un proxy, toy, mock, extraction ou harnais ne qualifie une propriété réelle que s'il exerce effectivement la propriété qu'il prétend tester. Ce principe doit rester proportionné : ne pas ajouter un test coûteux lorsqu'une source ou une trace déjà disponible possède le pouvoir discriminant nécessaire.

## 6. Dézoom systémique appliqué aux cycles

Lorsqu'un problème local persiste ou se répète, vérifier si le niveau causal est :

- le candidat scientifique lui-même ;
- la relation entre plusieurs accès ;
- le dispositif expérimental ou inférentiel ;
- le modèle ou la paramétrisation ;
- le harnais computationnel ;
- la représentation documentaire de l'état scientifique.

S'arrêter au premier niveau où un test discriminant peut réellement départager les causes. Ne pas convertir ce dézoom en audit global automatique du cycle.

## 7. Cycle 7 — règle locale renforcée

Pour `07_Cycle_cosmologique/`, lire également son point d'entrée local avant toute action.

Les lignes `C7-C1 / X(z) / SCI-1` et `C7-GAL` sont indépendantes. Aucun état MCMC, aucune porte B1/SCI-1, aucune dette matérielle ni autorisation ne se transfère de l'une à l'autre sans décision explicite.

Une erreur machine doit être reproduite et localisée avant d'être attribuée au candidat scientifique.

## 8. Promotions et mises à jour documentaires

Une nouvelle question scientifique, un modèle, une donnée, un prior, une paramétrisation scientifique, un seuil d'évidence, une interprétation ou un verdict durable restent des frontières humaines.

Les synchronisations documentaires qui rendent un état déjà décidé correctement récupérable peuvent être exécutées de manière bornée sans créer une nouvelle décision scientifique.

Lorsqu'un cycle change réellement d'état, mettre à jour son point d'entrée ou son ancrage actif plutôt que laisser l'information uniquement dans une conversation ou une issue secondaire.
