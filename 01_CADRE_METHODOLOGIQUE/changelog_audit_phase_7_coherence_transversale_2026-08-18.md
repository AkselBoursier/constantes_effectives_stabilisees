## 2026-08-18 — T1–T2 : questions, centres et dépendances

Les centres locaux sont distincts : constitution (Saveur–Higgs), validité de
description (EFT), inférence/reconstruction (cosmologie), définition/réalisation
(SI), bornes et accès hétérogènes (neutrinos). Cette diversité est confirmée
par les audits de resynchronisation et de cycles.

```text
T1 = JUSTIFIEE_DANS_LE_PERIMETRE
T2 = JUSTIFIEE_DANS_LE_PERIMETRE
FUSION_DES_CENTRES = REFUSEE
```

Les dépendances locales sont toutefois réelles : `v` et le seuil électrofaible
alimentent Saveur–Higgs ; le SI éclaire localement définition/réalisation ; l'EFT
éclaire domaine/limite ; la cosmologie relie modèle, accès, reconstruction et
tension ; les neutrinos relient plusieurs fonctions d'un secteur latent.

Ces relations restent directionnelles et conditionnelles. Elles ne transfèrent
ni verdict, ni autorisation, ni rang entre cycles.

```text
DEPENDANCES_LOCALES = ETABLIES
TRANSFERT_AUTOMATIQUE_DE_VERDICT = REFUSE
UNITE_PHYSIQUE_GENERALE = NON_ETABLIE
```

## 2026-08-18 — T3–T5 : couches, portée et état documentaire

Les concepts F1–F8 et les règles D1–D5 servent d'interfaces de contrôle. Ils
permettent de conserver la distinction entre résultat scientifique, fonction
conceptuelle, contrôle méthodologique et instrument philosophique.

La branche philosophique est compatible avec ces interfaces comme appareil de
classement et de limitation ; elle n'en dérive aucune conséquence scientifique
ou ontologique.

Les documents, issues et Git portent des fonctions différentes : les pièces
scientifiques portent leurs résultats locaux, les issues portent les portes et
états mouvants, les journaux portent la traçabilité, et Git porte l'historique.
Aucune couche ne remplace les autres.

```text
T3 = JUSTIFIEE_DANS_LE_PERIMETRE
T4 = COMPATIBILITE_BORNEE, DERIVATION_NON_ETABLIE
T5 = JUSTIFIEE_DANS_LE_PERIMETRE
ETAT_SUBSTANTIEL = NON_RECONSTRUIT_PAR_LE_SEUL_ROUTAGE
```
