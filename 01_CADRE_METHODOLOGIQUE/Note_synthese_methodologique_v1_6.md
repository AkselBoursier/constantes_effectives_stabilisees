# Note de synthèse méthodologique v1.6

## Recherche, gouvernement du corpus et contrainte des LLM

### 0. Statut

```text
statut : note méthodologique active ;
remplace pour l’usage courant : Note_synthese_methodologique_v1_5.md ;
conserve la v1.5 : comme état daté antérieur aux décisions P23–P26 ;
fonction : articuler la méthode de recherche, le pilotage documentaire et les
           contraintes de rédaction avec des grands modèles de langage (LLM) ;
ne vaut pas : résultat physique, doctrine générale des LLM, méthodologie publique
              déjà validée au-delà de ce projet.
```

La v1.6 applique une règle temporelle générale : un document est interprété depuis
sa situation propre. Il faut distinguer :

```text
date de rédaction ;
date de dernière modification ;
autorité normative actuelle ;
état d’application documentaire.
```

L’état intellectuel courant est donné par la décision humaine validée la plus récente
qui demeure applicable. La qualité rédactionnelle, la longueur, la répétition ou la
simple date d’un fichier ne lui confèrent pas une autorité canonique.

## 1. Trois couches méthodologiques

### 1.1 Méthode de recherche

Cette couche porte les opérations susceptibles d’être publiquement défendues :

```text
poser une question ;
identifier les cas et les transformations ;
rechercher et contrôler les sources ;
distinguer les niveaux ;
éprouver les propositions ;
conserver les résultats négatifs et les suspensions ;
borner les conclusions.
```

Elle appartient directement au projet scientifique et philosophique.

### 1.2 Gouvernement interne du corpus

Cette couche assure la continuité du projet :

```text
provenance ;
datation ;
versions ;
issues ;
précédence des décisions ;
validation humaine ;
application documentaire ;
contrôle de synchronisation.
```

Elle ne prouve rien sur les objets physiques. Elle garantit que les décisions restent
reconstructibles et que les divergences entre états ne sont pas résolues
silencieusement.

### 1.3 Contrainte rédactionnelle et logique des LLM

Cette couche vise les risques propres au travail assisté par modèles :

```text
aplatissement temporel des documents ;
généralisation d’un terme local ;
promotion par répétition ;
fermeture prématurée d’une question ;
synthèse rhétorique de différences de rang ;
transformation d’une ellipse conversationnelle en catégorie canonique ;
effacement d’un refus, d’une suspension ou d’une dette.
```

Cette couche reste interne. Son éventuelle portée générale devra être établie par des
tests supplémentaires, non présumée.

## 2. Règle de lecture temporelle et normative

Tout document antérieur est lu comme un état de son moment. Une décision plus récente
peut :

```text
conserver un résultat local ;
requalifier un terme ;
restreindre une portée ;
modifier une précédence ;
créer une dette d’application.
```

Elle ne transforme pas automatiquement le document antérieur en erreur. Les sources,
archives, explorations et états datés ne sont pas réécrits rétrospectivement pour
simuler une cohérence qui n’existait pas encore.

Lorsqu’une décision validée n’est pas encore appliquée, l’écart doit être nommé :

```text
état normatif courant
≠ état documentaire appliqué.
```

## 3. Deux régimes de travail terminologique

### 3.1 Régime exploratoire

Les mots provisoires, analogies et regroupements sont autorisés lorsqu’ils rendent
l’enquête possible. Leur fonction est de permettre la recherche avant que toutes les
distinctions soient disponibles.

Dès qu’un terme commence à se propager, il doit recevoir un balisage proportionné :

```text
statut provisoire ;
fonction recherchée ;
cas ayant motivé le terme ;
portée locale présumée ;
confusions connues ;
condition de réexamen.
```

L’exploration peut aller plus vite que la ratification. Cette asymétrie est admise,
mais ne doit plus devenir invisible.

### 3.2 Régime de ratification

La permissivité cesse pour les termes stratégiques. Selon le cas, le terme doit subir :

```text
test de nécessité ;
test d’ablation ;
comparaison au vocabulaire existant ;
épreuve sur cas positifs, négatifs et suspendus ;
détermination du rang ;
conditions d’usage et de rupture ;
validation humaine ;
application documentaire séparée.
```

Le passage d’un régime à l’autre n’est pas automatique. Une formulation peut être
féconde dans l’exploration et néanmoins être restreinte ou abandonnée lors de la
ratification.

## 4. Médiation humaine et médiation algorithmique

Les glissements terminologiques ne sont attribués ni à l’auteur seul ni aux LLM seuls.
Leur trajectoire doit être reconstruite par questions :

```text
d’où vient la formulation ?
quel était son statut ?
qu’a-t-elle permis ?
qu’a-t-elle masqué ?
quand a-t-elle été répétée ?
quand a-t-elle été ratifiée ou requalifiée ?
où reste-t-elle encore appliquée ?
```

Une trajectoire fréquente est :

```text
intuition insuffisamment différenciée
+ terme provisoire proposé par l’auteur
+ permissivité humaine envers son imprécision
+ traduction, systématisation et généralisation par les LLM
+ répétition documentaire
→ apparence progressive de concept canonique.
```

Cette causalité est conjointe sans être symétrique. L’auteur fournit des intuitions,
analogies et ellipses ; le modèle peut leur donner une systématicité, supprimer leurs
hésitations et réutiliser cette cohérence produite comme preuve rétrospective.

Les témoignages rétrospectifs de l’auteur sont conservés comme données de conduite du
projet, non comme preuve qu’un protocole complet avait été conçu dès l’origine.

## 5. Noyau de l’enquête

Deux questions publiques organisent le travail :

1. Comment les sciences établissent-elles, utilisent-elles et déplacent-elles la
   frontière entre ce qui varie et ce qui tient ?
2. Par quelles structures, opérations et chemins de détermination un maintien
   devient-il opératoire ou affirmable dans un régime, et que change cette
   reconstruction pour l’enquête scientifique ?

La question de portée physique, épistémologique ou ontologique (`Q3`) reste un
contrôle interne obligatoire et non public.

La méthode distingue :

```text
constance de la cible ;
constitution ou conditions d’opérativité ;
accès, preuve et limites.
```

Aucun ordre universel n’est imposé. La porte d’entrée dépend du terrain.

## 6. Cinq passes de l’analyse

### 6.1 Passe A — constitution ou conditions d’opérativité

Questions :

```text
dans quelles conditions la cible devient-elle pertinente ?
de quels éléments dépend-elle ?
quel mécanisme ou quelle opération intervient ?
qu’est-ce qui est produit, maintenu ou seulement rendu définissable ?
quelle condition défait ou déplace le régime ?
quelle dette constitutive demeure ?
```

Sorties possibles : mécanisme physique, architecture, validité héritée d’un régime,
définition et réalisation, relation formelle, paramètre libre, constitution inconnue
ou question non pertinente.

### 6.2 Passe B — identification de la cible et du maintien

Contrôle minimal :

```text
porteur du test : P ;
transformation : T ;
régime : R ;
échelle et schéma : S ;
tolérance : epsilon ;
durée ou domaine : D ;
rupture : E.
```

Le `porteur du test` est une fonction analytique relative à l’énoncé. Il ne désigne
ni un substrat ni une catégorie ontologique.

### 6.3 Passe C — différenciation conceptuelle et physique

Cette passe demande :

```text
qu’est-ce que ce cas partage avec d’autres cas appelés constantes ?
qu’est-ce qui l’en distingue physiquement ?
quelle dépendance serait perdue par une table plate ?
quel vocabulaire disciplinaire local doit être conservé ?
quelle différence de rang ne doit pas être synthétisée ?
```

La différenciation ne produit pas nécessairement une taxonomie.

### 6.4 Passe D — qualification éventuelle

La sortie de T0 est normative :

```text
admission ;
refus ;
suspension ;
qualification non pertinente pour la question étudiée.
```

Statuts disponibles :

```text
constance physique ;
constance effective ;
constance métrologique ;
usage historique ou disciplinaire du mot constante.
```

Les statuts qualifient des énoncés indexés, non des grandeurs nues.

### 6.5 Passe E — accès, preuve et limites

Distinguer :

```text
mesure ;
ajustement ;
inférence ;
reconstruction ;
borne ;
non-détection ;
définition ;
réalisation ;
comparaison de routes ;
contrainte sur une variation.
```

Cette passe établit la force probatoire, sépare la cible de son estimation, indique
les dépendances de modèle et conserve ce qui ne peut pas être conclu.

## 7. Décisions terminologiques actives

### 7.1 Stabilisation

Terme méthodologique de second ordre. Il désigne l’établissement, la consolidation ou
le maintien de conditions grâce auxquelles un état, un régime, une réalisation, une
estimation ou une attribution devient opératoire ou soutenable selon un critère.

Il ne remplace ni le maintien de la cible, ni sa constitution, ni le mécanisme local,
ni l’explication.

### 7.2 Porteur du test

Fonction analytique désignant la cible précise d’une attribution. Employer de
préférence `porteur du test` ou `cible de l’attribution`, et non `porteur` comme
catégorie substantielle.

### 7.3 Fixité qualifiée

Expression généalogique déclassée. Employer :

```text
maintien sous transformations déclarées,
dans un régime,
à une tolérance,
avec condition de rupture.
```

### 7.4 Constante effective / constance effective

`Constante effective` est abandonné comme classe transversale du projet.

`Constance effective` reste un statut d’énoncé lorsqu’une cible est traitée comme
maintenue dans une approximation contrôlée, à un ordre et une tolérance déclarés,
avec corrections et rupture explicites.

Les usages disciplinaires restent premiers : constante de Fermi, constante de basse
énergie, constante de couplage, coefficient de Wilson, etc.

Ordre de publication :

```text
vocabulaire disciplinaire local
→ description du cas
→ conditions du test
→ verdict analytique éventuel.
```

## 8. Cas de contrôle

| Cas | Cible | Verdict | Contrôle principal |
|---|---|---|---|
| `G_F` | coefficient du terme dominant de la théorie de Fermi | constance effective à basse énergie sous indexation stricte | ordre, corrections et rupture en `q²/M_W²` |
| coefficient de Wilson générique | coefficient dans une base, un schéma et une échelle | aucun statut automatique | running, mélange et dépendance de base |
| `alpha_s(mu)` | couplage courant | refus de constance sous variation de `mu` | groupe de renormalisation |
| constante de basse énergie chirale | paramètre disciplinaire local | verdict individuel requis | ordre, schéma, échelle et ajustement |
| `h` dans le SI | valeur numérique dans le système d’unités | constance métrologique | définition, réalisation et incertitudes pratiques |
| `H_0` | valeur actuelle de `H(t)` | paramètre d’état, non constante nomologique | époque, modèle et accès |
| masse absolue neutrino | ancrage du spectre | qualification suspendue | projections et bornes hétérogènes |
| CKM / PMNS | propositions décomposées sur matrices et invariants | aucun verdict global | constitution de secteur et accès |
| quasi-stationnarité dynamique | comportement dans une trajectoire ou une fenêtre | aucun statut automatique | bassin, coût, durée et devenir énergétique |

## 9. Fonction du dispositif GitHub

Le dispositif ne doit pas empêcher l’exploration d’employer des termes imparfaits.
Il doit empêcher qu’ils acquièrent silencieusement une autorité canonique par
répétition.

Chaîne de contrôle :

```text
intuition
→ formulation exploratoire
→ propagation balisée
→ instruction
→ ratification, restriction ou abandon
→ décision humaine
→ application documentaire
→ vérification de synchronisation.
```

Les issues de décision ne remplacent pas les documents scientifiques. Les documents
scientifiques ne remplacent pas les décisions de rang. L’application aux fichiers est
une opération distincte de la validation intellectuelle.

## 10. Dette généalogique

Une enquête ultérieure pourrait reconstruire les trajectoires réelles de termes tels
que :

```text
constante effective stabilisée ;
constance stabilisée ;
fixité dynamique ;
fixité qualifiée ;
porteur ;
autres glissements encore non identifiés.
```

Cette enquête pourrait exiger d’autres répertoires locaux, archives conversationnelles
et états intermédiaires. Elle n’est pas présumée réalisable à partir du seul dépôt
actuel et ne doit pas interrompre les unités scientifiques prioritaires.

## 11. Conditions d’échec

La méthode échoue si elle :

1. transforme toute dépendance en constitution ;
2. présuppose une genèse temporelle pour tout maintien ;
3. raconte une histoire sans mécanisme ou condition vérifiable ;
4. confond constitution de relation, de maintien et de valeur ;
5. réduit la différenciation à une taxonomie plate ;
6. fait de la qualification terminologique le but de tous les cas ;
7. néglige les dépendances de modèle ;
8. présente une quasi-stationnarité locale comme histoire réelle acquise ;
9. traite les documents antérieurs comme contemporains ;
10. donne au texte le plus développé une autorité automatique ;
11. transforme un usage disciplinaire en verdict du cadre ;
12. nettoie rétrospectivement les archives pour simuler une stratégie parfaite ;
13. attribue tous les glissements à l’auteur ou tous aux LLM ;
14. empêche l’exploration au nom d’une rigueur qui ne peut être complète dès l’origine.

## 12. Formule de clôture

> Le projet autorise l’exploration à produire des formulations imparfaites, mais il
> sépare leur fécondité de leur autorité. Il reconstruit les cibles, les mécanismes et
> les accès, puis soumet les termes stratégiques à une ratification humaine. La
> méthode publique porte les preuves ; le gouvernement interne conserve les rangs et
> les versions ; la contrainte des LLM empêche qu’une répétition devienne une décision.
