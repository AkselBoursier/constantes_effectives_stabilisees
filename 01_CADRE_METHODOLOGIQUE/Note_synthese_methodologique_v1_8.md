La v1.8 conserve les décisions P27–P28 et précise leur articulation. P27 distingue le

## 1. Trois couches méthodologiques

### 1.1 Méthode de recherche

```text
poser une question ;
identifier la cible et les transformations ;
rechercher et contrôler les sources ;
distinguer objet, constitution et accès ;
éprouver des cas positifs, négatifs et suspendus ;
conserver les résultats négatifs ;
borner les conclusions.
```

### 1.2 Gouvernement interne du corpus

```text
provenance ;
datation ;
versions ;
issues ;
précédence des décisions ;
validation humaine ;
application documentaire ;
contrôle de synchronisation.
```

Cette couche ne prouve rien sur les objets physiques. Elle empêche qu’une différence
entre états soit résolue silencieusement.

### 1.3 Contrainte rédactionnelle et logique des LLM

```text
aplatissement temporel des documents ;
généralisation d’un terme local ;
promotion par répétition ;
fermeture prématurée d’une question ;
synthèse de différences de rang ;
transformation d’une ellipse en catégorie canonique ;
effacement d’un refus, d’une suspension ou d’une dette.
```

Sa portée générale éventuelle reste à établir ; elle n’est pas présumée par son utilité
interne.

## 2. Règle temporelle et normative

Tout document est lu depuis sa situation propre. Distinguer :

```text
date de rédaction ;
date de dernière modification ;
autorité normative actuelle ;
état d’application documentaire.
```

L’état intellectuel courant est donné par la décision humaine validée la plus récente
qui demeure applicable. Un document antérieur peut conserver un résultat local valide
alors que son vocabulaire ou son rang a été requalifié.

Lorsqu’une décision validée n’est pas encore appliquée :

```text
état normatif courant
≠
état documentaire appliqué.
```

## 3. Qualification d’une constance

La sortie de T0 reste normative :

```text
admission ;
refus ;
suspension ;
qualification non pertinente pour la question étudiée.
```

Les statuts disponibles restent :

```text
constance physique ;
constance effective ;
constance métrologique ;
usage historique ou disciplinaire du mot constante.
```

Aucun statut supplémentaire n’est créé par P27. Les statuts qualifient des énoncés
indexés, non des grandeurs nues.

Contrôle minimal :

```text
porteur du test : P ;
transformation : T ;
régime : R ;
échelle, schéma ou modèle : S ;
tolérance : epsilon ;
durée ou domaine : D ;
condition de rupture : E.
```

## 4. Résultat quantitatif, soutien probatoire et verdict — P27

P27 impose de distinguer :

```text
résultat quantitatif ;
mode de soutien probatoire ;
verdict de constance.
```

Une borne, une compatibilité avec zéro ou une tension statistique ne déterminent pas à
elles seules le verdict.

### 4.1 Mode de soutien probatoire

Le `mode de soutien probatoire` est une coordonnée descriptive de l’accès. Il indique
comment l’attribution est soutenue, affaiblie ou suspendue. Il ne constitue pas une
nouvelle espèce de constance.

```text
mesure directe d’un maintien ;
comparaison entre régimes ou époques ;
contrainte sensible sur une variation ;
non-détection non discriminante ;
conflit entre accès commensurables ;
repondération après identification de systématiques ;
couverture partielle du domaine ;
qualification probatoire suspendue.
```

### 4.2 Borne sur la valeur et borne sur la variation

```text
borne sur la valeur de P
≠
borne sur la variation de P.
```

Une borne sur la valeur ne produit pas une valeur positive de la cible. Une borne sur
une variation peut soutenir une attribution relative de constance lorsqu’elle provient
d’un test suffisamment discriminant.

### 4.3 Non-détection discriminante

Une non-détection ne soutient une constance que si sont contrôlables :

```text
transformation déclarée ;
famille de variations testée ;
puissance de détection suffisante ;
identifiabilité de la cible ;
modèle de conversion explicite ;
paramètres de nuisance et systématiques contrôlés ;
domaine et tolérance de la conclusion.
```

Formulation admissible :

> Aucune variation de la forme M n’est détectée pour la cible P, sous la transformation
> T, dans le domaine D, à la tolérance epsilon.

Cette formulation ne devient pas :

> P est exactement et universellement invariante.

### 4.4 Charge de la preuve

Les prétentions de constance et de variation sont soumises aux mêmes exigences de cible,
transformation, sensibilité, systématiques, modèle, domaine, tolérance et condition
d’échec. Les inférences restent asymétriques :

```text
variation : signal positif robuste, signature attendue et réplication si possible ;
constance : absence de variation dans un test capable de détecter les variations
            pertinentes, avec tolérance et domaine déclarés.
```

`Significatif` et `compatible avec zéro` ne sont pas des verdicts conceptuels.

### 4.5 Conflit entre accès

Un désaccord numérique ne suffit pas à créer une catégorie de `constance contestée`.
Comparer :

```text
cible effectivement reconstruite ;
commensurabilité des accès ;
modèles de conversion ;
couverture des domaines ;
calibrations ;
systématiques ;
indépendance des données ;
qualité probatoire relative.
```

L’identification d’un biais dans une route transforme le conflit en repondération
asymétrique. Une mesure plus récente ou plus précise ne reçoit pas une autorité
automatique hors de son domaine.

### 4.6 Prolongement réflexif de P27

L’absence d’un incident déjà formalisé ne démontre pas l’absence d’un besoin documentaire
lorsque le dispositif existant n’avait pas la puissance discriminante nécessaire pour
rendre ce besoin observable.

```text
absence de signal
≠
non-détection discriminante ;

absence d’incident documenté
≠
inutilité démontrée d’un support exploratoire.
```

Cette analogie sert de contrôle contre une inférence négative trop rapide. Elle ne
transforme pas P27 en théorie générale du gouvernement documentaire.

## 5. Cas adversariaux de P27

### 5.1 Variation temporelle de G

```text
constance physique relative : admise dans les régimes et familles testés ;
mode de soutien : contraintes sensibles sur une variation temporelle ;
portée : locale, temporelle et dépendante du modèle ;
interdit : promotion en invariance exacte, universelle ou cosmologique de G.
```

### 5.2 Dossier Webb sur alpha

```text
variation dipolaire historique : prétention positive probatoirement dégradée ;
invariance sur certaines lignes de visée : corroborée à la tolérance atteinte ;
invariance cosmologique globale : non établie ;
verdict au-delà des domaines testés : suspendu.
```

Le dossier illustre une repondération des accès plutôt qu’une symétrie durable entre une
détection et une non-détection.

## 6. Deux régimes de travail

### 6.1 Exploration

L’exploration autorise les formulations, distinctions, matrices, notes et regroupements
provisoires lorsqu’ils rendent l’enquête possible. Leur propagation significative exige
un balisage proportionné :

```text
statut exploratoire ;
question ou fonction recherchée ;
cas d’origine ;
portée locale ;
confusions connues ;
absence d’autorité normative ;
condition de réexamen ou de sortie.
```

Un support exploratoire peut être créé lorsqu’il réduit la charge cognitive ou permet
une épreuve qui ne peut être menée clairement dans les couches existantes. Il n’a pas à
remplacer une couche existante et ne contracte aucune obligation de maintenance durable.

À la fin de l’instruction, il est :

```text
abandonné ;
absorbé dans une couche existante ;
conservé comme état daté ;
ou soumis à ratification durable.
```

### 6.2 Ratification

Un terme stratégique ou un support destiné à la couche active doit subir, selon le cas :

```text
test de nécessité ;
test d’ablation ;
comparaison au vocabulaire ou aux couches existantes ;
épreuve sur cas positifs, négatifs et suspendus ;
détermination du rang ;
conditions d’usage et de rupture ;
gain discriminant ;
coût de maintenance ;
validation humaine ;
application documentaire séparée.
```

La fécondité exploratoire ne produit aucune ratification rétroactive.

## 7. Règle d’ablation documentaire différenciée — P28

> L’appareil de rigueur ne doit pas devenir un second projet dont la croissance
> concurrence la recherche qu’il doit protéger.

P28 régit la création ou la promotion des **artefacts durables de gouvernement du
corpus**. Elle n’interdit pas les supports exploratoires temporaires nécessaires pour
rendre une question, une distinction ou un conflit inspectable.

Formule active :

> **L’exploration peut créer ; seule la ratification autorise à conserver durablement et
> à faire autorité.**

### 7.1 En régime exploratoire

Exigences minimales :

```text
statut exploratoire ;
question ou fonction ;
absence d’autorité normative ;
condition de sortie.
```

La règle de remplacement d’une couche existante ne s’applique pas à la naissance d’un
support temporaire.

### 7.2 En régime de ratification

La promotion en artefact durable exige :

```text
besoin ou incident établi ;
solution légère insuffisante ;
gain discriminant ;
couche existante remplacée ou simplifiée ;
réduction nette de la maintenance ;
validation humaine.
```

À défaut, le support est abandonné, absorbé ou conservé comme état daté sans autorité
active.

P28 est donc :

```text
stricte sur la sédimentation ;
permissive sur l’essai ;
vigilante sur le passage de l’un à l’autre.
```

### 7.3 Verdicts particuliers inchangés

```text
STATUTS_ACTIFS.md : non créé ; fonction intégrée à l’index courant ;
ENTREE_SESSION.md supplémentaire : non créée ;
registre exhaustif de certificats conceptuels : abandonné ;
nouvelle taxonomie de statuts : abandonnée ;
restructuration massive des archives : abandonnée.
```

Les fonctions durables restent distribuées ainsi :

```text
README : entrée humaine et statut condensé ;
AGENTS.md : amorçage opérationnel et interdits ;
index raisonné : état détaillé, navigation et rangs ;
issues : décisions validées et dettes d’application ;
Git et registre court : continuité et provenance ;
glossaire : terminologie active.
```

Les archives ne reçoivent que des corrections locales motivées par un incident concret.

## 8. Médiation humaine et algorithmique

Les glissements terminologiques sont reconstruits sans attribuer toute la causalité à
l’auteur ou aux LLM :

```text
intuition insuffisamment différenciée
+ terme provisoire
+ permissivité humaine
+ traduction et systématisation par les LLM
+ répétition documentaire
→ apparence progressive de concept canonique.
```

Les témoignages rétrospectifs de l’auteur restent des données de conduite du projet, non
la preuve qu’un protocole complet existait dès l’origine.
